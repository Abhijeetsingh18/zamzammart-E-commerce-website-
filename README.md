# 🛒 ZamZam Mart — Fullstack E-Commerce Grocery Platform

A modern, fullstack online supermarket and grocery platform built with **Spring Boot 3 (Java 21)** on the backend and **React + Vite + Tailwind CSS** on the frontend.

## 🌐 Live Demo

🚀 **[ZamZam Mart | Pure, Fresh & 100% Certified Grocery Supermarket](https://client-phi-umber-99.vercel.app/)**

## 🌟 Key Features

### 🛍️ Customer Experience

- **100% Halal & Farm Fresh Catalog**
  - High-definition product imagery
  - Halal-certified tags
  - Weight/unit indicators
  - Discount tags

- **Dynamic Category Explorer**
  - Fresh Fruits & Vegetables
  - Halal Meats & Poultry
  - Dairy & Eggs
  - Bakery & Delights
  - Rice & Pantry
  - Dates & Dry Fruits
  - Beverages

- **Smart Live Search & Sorting**
  - Search by product name
  - Search by description
  - Filter by category
  - Sort by price
  - Sort by rating
  - Client-side and server-side filtering

- **Shopping Cart & Checkout**
  - Live quantity steppers
  - Cart drawer
  - Coupon code discounts
  - Free delivery progress bar
  - Multi-step checkout
